# 폐기된 파이프라인 — 손으로 그린 house.mjs → Studio 로 밀어넣기

여기 있던 도구들은 `house.mjs`(손으로 그린 32×32 집 도면)를 SPUM Studio 맵으로
구워서 올리는 **옛 방향**의 파이프라인이다.

지금은 방향이 반대다: **SPUM Studio(Cozy Supermarket 월드)가 정본**이고,
`spum/spummap.mjs` 가 `spum/supermarket-map.json` 을 그대로 읽어 게임을 그린다.
`house.mjs` 의 SPOT·ZONES·방 이름과 `house-map.json`(삭제됨)은 더 이상 게임이 쓰지 않는다 (2026-08-21 이전 대화 기록 참고).

옛 집 도면이 다시 필요해지면 여기서 꺼내 쓰면 되고, 아니면 그냥 참고용으로만 남겨둔다.
